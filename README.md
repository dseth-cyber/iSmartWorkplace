# iSmart Workplace — สรุปฟังก์ชันหลักของโปรแกรม

โปรแกรมนี้รวม 2 ระบบไว้ในตัวเดียว: **จัดการไฟล์ Backup/Cleanup/Sync** และ **แชท LAN ในองค์กร**

## 1) จัดการไฟล์ (Backup / Cleanup / Sync)

**ประเภทงานที่ทำได้ 4 แบบ:**
- **ลบอย่างเดียว** — ลบไฟล์เก่ากว่าอายุที่กำหนด (วัน/เดือน/ปี ตามวันที่สร้างหรือแก้ไขล่าสุด) ไปถังขยะหรือลบถาวร รวมลบโฟลเดอร์ย่อยที่ว่างได้
- **Copy** — คัดลอกไฟล์ทุกชั้นไปปลายทาง ต้นทางไม่หาย เลือกข้ามหรือแทนที่ไฟล์ซ้ำได้
- **Backup** — สำรองข้อมูลเป็นชุดแยกโฟลเดอร์ทุกครั้งที่รัน ตั้งอายุลบชุดเก่าอัตโนมัติได้ (เก็บทะเบียนชุดไว้ใน SQLite กันลบผิด)
- **Sync ทางเดียว** — ตรวจ SHA-256 แล้วซิงก์ปลายทางให้ตรงต้นทาง เลือกลบไฟล์ส่วนเกินที่ปลายทางได้

**ความปลอดภัยของข้อมูล:** ทดลองสแกนดูผลก่อนรันจริงได้เสมอ, การลบ/แทนที่ถาวรต้องพิมพ์ยืนยัน "DELETE", คัดลอกผ่านไฟล์ชั่วคราว+ตรวจ SHA-256 ก่อนใช้จริง, กันเลือกไดรฟ์/โฟลเดอร์ระบบผิดพลาด, ไม่มีการลบต้นทางในงาน Copy/Backup/Sync

**ตารางเวลาอัตโนมัติ:** ตั้งได้ทุกวัน/ทุกสัปดาห์/ทุก N ชั่วโมงต่องาน, พักหรือหยุดงานได้, ทำงานผ่าน System Tray, มี Log และประวัติงานย้อนหลังพร้อมส่งออก CSV

## 2) แชท LAN ในองค์กร

**พื้นฐานแชท:** ข้อความตัวต่อตัว/กลุ่ม/สาขา/ประกาศถึงทุกคน, ส่งไฟล์แนบ (สูงสุด 50MB), รูปภาพแสดงเป็นแกลเลอรีขนาดย่อ, วิดีโอมีภาพตัวอย่างพร้อมปุ่มเล่น, สติกเกอร์, ตอบกลับ/แชร์/เรียกคืน/ลบข้อความ, สถานะถึง/อ่านแล้ว, เสียงแจ้งเตือนพร้อมปิดเสียงได้

**ไฟล์และรูปภาพ:** บันทึกรูป/วิดีโอ/ไฟล์แนบได้ทั้งแบบด่วน (ปุ่มมุมรูป) และแบบเปิดดูก่อน, มีลิงก์ "แชร์" ต่อทันทีและ "เปิดโฟลเดอร์" หลังบันทึก, รูปกลุ่มมีปุ่ม "แชร์ทั้งหมด"/"บันทึกทั้งหมด" ในคลิกเดียว, คิวส่งไฟล์หลายไฟล์พร้อมการ์ดแจ้งความคืบหน้า

**การโทร:** โทรเสียงในวง LAN ผ่าน WebRTC, รองรับตั้งค่า STUN/TURN สำหรับโทรข้ามเครือข่ายในอนาคต

**การจัดการองค์กร/ผู้ดูแล:** ผู้ดูแล (Admin) จัดการสมาชิกได้จริงในแอป (ระงับ/เลื่อนเป็นผู้ดูแล/ลบสมาชิกถาวร), เชื่อมต่อผ่าน LAN อัตโนมัติหรือรหัสเชิญ, รองรับเชื่อมต่อข้าม VLAN แบบระบุ IP เอง, รองรับเครื่องได้หลักร้อยพร้อมกัน (ส่งข้อความ/ไฟล์แบบขนาน)

**ความปลอดภัย:** เข้ารหัสข้อความ/ไฟล์แบบ end-to-end ระหว่างเครื่อง, Server กลางทำหน้าที่แค่รายชื่อ/กลุ่ม ไม่เก็บเนื้อหาข้อความจริง, มี Relay สำรองเมื่อเชื่อมต่อตรงไม่ได้

**อินเทอร์เฟซ:** รองรับภาษาไทย/อังกฤษ, ธีมสว่าง/มืด, แยกหน้าต่างแชทเดี่ยวได้, รายการสนทนาซ่อนอัตโนมัติเมื่อล้างประวัติแล้วไม่มีข้อความเหลือ

### 3. การตั้งค่าเชื่อมต่อแบบ Manual ข้าม VLAN

| ช่องตั้งค่า | ค่ามาตรฐานที่ถูกต้อง | คำแนะนำการใช้งาน |
|---|:---:|---|
| **IP ของ Server** | `192.168.x.x` | ใส่ IP จริงของเครื่อง Server |
| **พอร์ต Server** | `48731` | พอร์ตมาตรฐานของ Directory Server |
| **SHA-256 ของ Server** | รหัส 64 ตัวอักษร | คัดลอกจากหน้าจอ Console ของ Server มากรอก |
| **IP เครื่องนี้** | `0.0.0.0` | ผูกทุก Interface เครือข่ายในเครื่อง |
| **พอร์ตรับข้อความ** | `48733` | พอร์ตมาตรฐานสำหรับรับข้อความ P2P |
| **ตรวจ SHA-256** | ติ๊กถูก | ต้องติ๊กยืนยันก่อนกดบันทึก |

### 4. ขั้นตอนการติดตั้งและการใช้งาน

#### ฝั่งเครื่องแม่ (Directory Server)
1. แตกไฟล์ `iSmartWorkplace-3.6.8-Windows-x64.zip`
2. ดับเบิลคลิกเปิด `iSmartWorkplace-Server.exe` ทิ้งไว้ (คลิกขวาที่ Tray เพื่อสั่งซ่อนหน้าต่าง Console ได้)
3. หากต้องการเปิดใช้งานฟังก์ชันแชทหรือสำรองข้อมูลบนเครื่อง Server ด้วย ให้ดับเบิลคลิกเปิด `iSmartWorkplace.exe` หรือติดตั้งผ่าน `iSmartWorkplace-Setup.exe`

#### ฝั่งเครื่องลูก (Client)
1. วางไฟล์ `iSmartWorkplace.exe` ในตำแหน่งถาวร หรือติดตั้งผ่าน `iSmartWorkplace-Setup.exe` (ไม่ต้องติดตั้ง Python)
2. หากอยู่ในวง LAN เดียวกัน โปรแกรมจะค้นหา Server อัตโนมัติ
3. หากอยู่คนละวง LAN / ข้าม VLAN ให้ไปที่เมนู `เครือข่าย / เชื่อมต่อ Server` กรอกข้อมูลตามตารางด้านบนแล้วกด **"บันทึกและเชื่อมต่อ"** *(หากเคยเชื่อมต่อ Server ตัวอื่นมาก่อน ให้กด "ล้างการลงทะเบียนเครื่องนี้" ก่อน)*

#### การจัดการงาน Backup
- งานเก่าจะปรากฏในเมนู `โฟลเดอร์และตารางเวลา` เป็นงานลบอย่างเดียวโดยอัตโนมัติ แนะนำให้สั่งพักตารางเวลาเพื่อตรวจสอบก่อน
- แนะนำให้กด **"ทดลองสแกน"** แล้วตรวจสอบรายการใน `ประวัติการทำงาน → ดูรายละเอียด / CSV` ก่อนเปิดทำงานจริง
- ปิดหน้าต่างโปรแกรมเพื่อย่อลง System Tray ได้ตลอดเวลา
- สามารถตั้งค่าเริ่มโปรแกรมพร้อม Windows ได้ที่ `ตั้งค่าและวิธีใช้ → เปิดโปรแกรมใน Tray เมื่อเข้าสู่ระบบ Windows`<img width="1689" height="826" alt="image" src="https://github.com/user-attachments/assets/bf9d32c9-a9de-4b57-801b-edcffebcef9c" />
