### 1. สรุปความเปลี่ยนแปลงในเวอร์ชัน v3.6.8

- **แก้ปัญหาการเชื่อมต่อ Server ข้าม VLAN ไม่ได้:**
  - พบสาเหตุแท้จริงคือเครื่อง Client ที่เคย Enroll ผูกกับ Server เครื่องเดิมไว้ จะถูกบล็อกไม่ให้เชื่อมต่อกับ Server เครื่องใหม่โดยอัตโนมัติ
  - ปรับให้แสดงหน้าต่างแจ้งเตือนทันทีเมื่อเชื่อมต่อไม่สำเร็จ เพื่อไม่ให้สับสนว่าระบบหา Server ไม่เจอ
- **เพิ่มปุ่ม "ล้างการลงทะเบียนเครื่องนี้" (Reset Enrollment):**
  - เพิ่มในเมนู `เครือข่าย / เชื่อมต่อ Server` ช่วยให้สลับไปเชื่อมต่อ Server ตัวใหม่ได้ทันทีจากหน้าจอโปรแกรม โดยไม่ต้องตามไปลบไฟล์คอนฟิกเอง
- **จดจำสถานะการตรวจ SHA-256:**
  - ติ๊กถูกที่ช่อง *"ตรวจ SHA-256 กับผู้ดูแลแล้ว"* ให้อัตโนมัติเมื่อเปิดหน้าต่างขึ้นมาใหม่ด้วย IP และ Fingerprint เดิมที่เคยยืนยันแล้ว

### 2. ฟังก์ชันภาพรวมของระบบในเวอร์ชันนี้

- **ระบบ Backup & File Management:**
  - รองรับงาน 4 รูปแบบ: ลบอย่างเดียว, Copy, Backup (แยกโฟลเดอร์ตามรอบเวลา พร้อมตัวเลือกบีบอัด Zip และนับจำนวนชุดเก็บ Retention), และ Sync ทางเดียว
  - มีระบบทดลองสแกนจำลองผลลัพธ์ก่อนเริ่มทำงานจริง
  - ป้องกันไฟล์เสียหายด้วยการตรวจสอบความถูกต้องผ่าน SHA-256 Checksum
- **ระบบ LAN Chat (Hybrid P2P + Directory Server):**
  - ค้นหา Server ในวงเครือข่ายเดียวกันอัตโนมัติ (UDP Broadcast) หรือเชื่อมต่อแบบระบุ IP ข้าม VLAN
  - การส่งข้อความและไฟล์ส่งตรงระหว่างเครื่องแบบ P2P เข้ารหัส (รองรับไฟล์แนบสูงสุด 50 MB, แสดงตารางรูปภาพย่อ และตัวอย่างวิดีโอ)
  - รองรับการคลิกขวา/ดับเบิลคลิกแยกหน้าต่างแชท (Detached Window)
  - มีฟังก์ชันจับภาพหน้าจอ (Screenshot) ส่งลงแชทได้ทันที
  - ตัว Server มี System Tray Icon สำหรับย่อเก็บหน้าต่าง Console

### 3. การตั้งค่าเชื่อมต่อแบบ Manual ข้าม VLAN

| ช่องตั้งค่า | ค่ามาตรฐานที่ถูกต้อง | คำแนะนำการใช้งาน |
|---|:---:|---|
| **IP ของ Server** | `192.168.x.x` | ใส่ IP จริงของเครื่อง Server |
| **พอร์ต Server** | `48731` | พอร์ตมาตรฐานของ Directory Server |
| **SHA-256 ของ Server** | รหัส 64 ตัวอักษร | คัดลอกจากหน้าจอ Console ของ Server มากรอก |
| **IP เครื่องนี้** | `0.0.0.0` | ผูกทุก Interface เครือข่ายในเครื่อง |
| **พอร์ตรับข้อความ** | `48733` | พอร์ตมาตรฐานสำหรับรับข้อความ P2P |
| **ตรวจ SHA-256** | ติ๊กถูก | ต้องติ๊กยืนยันก่อนกดบันทึก |

### 4. ขั้นตอนการติดตั้งและการใช้งาน

#### ฝั่งเครื่องแม่ (Directory Server)
1. แตกไฟล์ `iSmartWorkplace-3.6.8-Windows-x64.zip`
2. ดับเบิลคลิกเปิด `iSmartWorkplace-Server.exe` ทิ้งไว้ (คลิกขวาที่ Tray เพื่อสั่งซ่อนหน้าต่าง Console ได้)
3. หากต้องการเปิดใช้งานฟังก์ชันแชทหรือสำรองข้อมูลบนเครื่อง Server ด้วย ให้ดับเบิลคลิกเปิด `iSmartWorkplace.exe` หรือติดตั้งผ่าน `iSmartWorkplace-Setup.exe`

#### ฝั่งเครื่องลูก (Client)
1. วางไฟล์ `iSmartWorkplace.exe` ในตำแหน่งถาวร หรือติดตั้งผ่าน `iSmartWorkplace-Setup.exe` (ไม่ต้องติดตั้ง Python)
2. หากอยู่ในวง LAN เดียวกัน โปรแกรมจะค้นหา Server อัตโนมัติ
3. หากอยู่คนละวง LAN / ข้าม VLAN ให้ไปที่เมนู `เครือข่าย / เชื่อมต่อ Server` กรอกข้อมูลตามตารางด้านบนแล้วกด **"บันทึกและเชื่อมต่อ"** *(หากเคยเชื่อมต่อ Server ตัวอื่นมาก่อน ให้กด "ล้างการลงทะเบียนเครื่องนี้" ก่อน)*

#### การจัดการงาน Backup
- งานเก่าจะปรากฏในเมนู `โฟลเดอร์และตารางเวลา` เป็นงานลบอย่างเดียวโดยอัตโนมัติ แนะนำให้สั่งพักตารางเวลาเพื่อตรวจสอบก่อน
- แนะนำให้กด **"ทดลองสแกน"** แล้วตรวจสอบรายการใน `ประวัติการทำงาน → ดูรายละเอียด / CSV` ก่อนเปิดทำงานจริง
- ปิดหน้าต่างโปรแกรมเพื่อย่อลง System Tray ได้ตลอดเวลา
- สามารถตั้งค่าเริ่มโปรแกรมพร้อม Windows ได้ที่ `ตั้งค่าและวิธีใช้ → เปิดโปรแกรมใน Tray เมื่อเข้าสู่ระบบ Windows`<img width="1675" height="827" alt="image" src="https://github.com/user-attachments/assets/5c3b84e1-3c9a-4e16-804e-665dae0fd8ec" />
